# Claude — Motion Reel 2026

A 15-second motion design showreel where every frame and every sound is generated by code:
no timeline, no keyframes placed by hand, no samples, no 3D engine.

- `showreel.mp4` — the rendered reel (1920×1080, 60 fps, motion blur, H.264 + AAC).
- `index.html` — the same reel running live in the browser, synced to the soundtrack.

## The eight shots

| # | Beats | Shot | What it shows off |
|---|-------|------|-------------------|
| 01 | 0–4 | A coral ball hops across *motıon* and lands as the dot of the i, then irises open | squash & stretch, arcs, follow-through |
| 02 | 4–8 | TIMING / SPACING / EASING, each animated the way it is defined; *feeling* arrives last | kinetic type, variable-font (wdth/wght) justification |
| 03 | 8–12 | 45 superformula shapes; each beat a new state ripples through the grid | procedural shape systems, wave staggers |
| 04 | 12–16 | 9 000 particles: explosion, curl-noise flow, FLOW, then a sphere | 240 Hz simulation baked once, sampled at any time |
| 05 | 16–20 | Type rings orbiting the particle sphere, then a dolly straight through it | hand-rolled perspective, per-glyph affine mapping |
| 06 | 20–24 | Domain-warped fBm liquid under glass lenses that magnify the shader's own source | GLSL, refraction, dispersion |
| 07 | 24–28 | A bento grid of live tiles that re-flows on every beat, then collapses into the dot | superposed spring physics, UI and data motion |
| 08 | 28–32 | The dot writes the name and lands as its full stop | the bookend |

## How it is made

- `src/engine.js` — timeline on a 128 BPM grid (15 s = 32 beats = 8 bars), camera shake from musical hits.
- `src/post.js` — WebGL2 back end: sub-frame accumulation in linear light (real motion blur), bloom,
  radial chromatic aberration, vignette and film grain.
- `src/type.js` — glyph-level typography on [fontkit](https://github.com/foliojs/fontkit) outlines, so variable axes animate per glyph.
- `src/scenes/*` — one module per shot. Every scene is a pure function of time, so frames can render in any order, in parallel.
- `tools/soundtrack.py` — the score and sound design, synthesised with numpy/scipy (kick, clap, hats, bass, supersaw stabs and pads,
  FM plucks and bells, risers, whooshes, impacts, convolution reverb, ping-pong delay, sidechain).
- `tools/render.mjs` — drives headless Chromium frame by frame (8 sub-frames per frame, 180° shutter).
- `tools/build.sh` — soundtrack → frames → MP4.

Fonts: Archivo, Instrument Serif and Geist Mono (SIL Open Font License, see `fonts/`).
